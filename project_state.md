## 1. Overview & Architecture
FilmCollab is a professional networking and creative collaboration platform for the film industry, designed with a bespoke Studio Noir aesthetic.
- **Frontend Stack**: Vite 5 + React 18 + TypeScript 5.8, Tailwind CSS, shadcn/ui components, Lucide icons, next-themes.
- **Hero & Media Integration**: Accepted 16:9 vintage golden reel looping video (`/media/main-reel.mp4`, poster `/media/main-reel-poster.webp`) with reduced-motion fallback, responsive framing, and Studio Noir layout.
- **Backend & Database**: Supabase (PostgreSQL 16 with Row Level Security, Supabase Auth, Storage buckets, Realtime). Clean chronological replay of all 25 timestamped migrations from `20250108000000_bootstrap_profiles_and_auth.sql` through `20261108000000_r7_complete_contract_and_security_remediation.sql`, verified against both clean-install and existing-schema upgrade paths in a real PostgreSQL 16 engine (`@electric-sql/pglite`).
- **Strictly Typed PostgREST Contracts**: `createClient<Database>` in `src/integrations/supabase/client.ts` with comprehensive typed schemas (`Tables`, `Views.public_profiles`, `Enums.app_role`, and `Functions`) in `src/integrations/supabase/types.ts` including custom server RPCs (`provision_admin_team_member`, `revoke_admin_team_member`, `send_authorized_notification`, `is_caller_active`, `is_global_admin`, `has_staff_permission`).
- **End-to-End Encryption (`src/lib/e2ee.ts`)**: Web Crypto API (ECDH P-256 key pair generation + AES-GCM 256-bit symmetric encryption) with authenticated 4-part key metadata (`ENCRYPTED:<keyId>:<iv>:<ciphertext>`, binding `ENCRYPTED:<keyId>` via AES-GCM `additionalData` and verifying `computeKeyId` to reject tampered headers with `E2EE_AUTHENTICATION_FAILED`), peer `public_key_history` decryption support across key rotations, explicit new-device key rotation confirmation before overwriting server `public_key`, non-destructive local key-ring, and fail-closed security for confidential direct messages and location enquiries.
- **Private Directory Storage (`src/lib/directory-storage.ts`)**: Non-public `directory_assets` and `directory_private` buckets (`public = false`) backed by `storage.objects` RLS, canonical `storage://directory_assets/<path>` URIs, signed URL resolution with client-side caching (`resolveDirectoryAssetUrl`, `resolveDirectoryFileUrls`), and orphan storage cleanup on database write failure (`cleanupUploadedStorageObjects`).
- **Quality & CI Gate**: Enforced via `.github/workflows/ci.yml`, `npx tsc -b --pretty false` (0 diagnostics), `npm test` (52 assertions across 21 suites, including real PostgreSQL 16 clean-install & upgrade execution via `@electric-sql/pglite`), `npm run build` (Exit code 0; `NewLocation` chunk reduced from `8,554.77 kB` to `25.25 kB`), and `npm run lint` (0 errors, Exit code 0).
